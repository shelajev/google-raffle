# Contributing

Issues and pull requests are welcome. Contributions are licensed under the
project's Apache License 2.0 unless explicitly agreed otherwise.

For artwork changes, include the exact prompt, model name, generation record,
and the source asset needed to reproduce the animation. Clearly distinguish
generated artwork from local processing and animation.

For animation changes, regenerate the GIF and preview, check the actual 64×64
output, and verify the last-to-first transition. Keep each submission file
below 5 MB. See README.md for reproduction commands.

Keep credentials, API keys, tokens, private badge QR data, and local environment
files out of commits. Generation uses the contributor's local Google login;
no credentials are required to reproduce the included animation.
